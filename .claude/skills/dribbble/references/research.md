# Field research

The goal is not inspiration. It is to know the visual default of a category
well enough to stand apart from it on purpose.

## Sources, in order of value

1. **The user's own material.** Screenshots of a Dribbble search, a saved
   collection, pasted shot URLs. Read the images; count the patterns.
2. **Web search.** `site:dribbble.com "<topic>"`, `site:dribbble.com/shots
   <industry> logo`, plus `dribbble.com/stories <topic>` for official articles.
   Titles and snippets show the field's vocabulary and which deliverables
   dominate.
3. **Curated tools, if connected.** Details MCP (`search_inspirations`), the
   `image-deep-research` skill (open-licence images, moodboard, palette and
   typeface reads of live sites).

Do not fetch or crawl dribbble.com pages in bulk: the developer terms forbid
scraping, and API v2 has no search. A single page the user explicitly hands
you is fine to read.

## What to look for

Name visual moves, not moods. Tally what you see:

- **Presentation format**: logo on embossed paper, 3D-rendered mockup, flat
  colour field, bento grid, phone in hand, glass and gradients.
- **Form language**: monogram, geometric symbol, wordmark, mascot, abstract blob.
- **Colour**: the default palette of the category (e.g. fintech is deep blue +
  neon green; coffee is brown + cream).
- **Type**: grotesk vs. serif vs. display; how much of it is in the image.
- **Copy**: how titles are phrased, which tags recur.

## Field brief template

```
FIELD BRIEF · <topic> · <date>

Sample: <n> shots / sources: <list>

What everyone does
- <move> (<x> of <n>)
- <move> (<x> of <n>)
- <move>

What nobody does
- <gap>
- <gap>

Where this project sits
<one or two sentences: the position, and the one visual decision it implies
for the shot series, e.g. "flat full-bleed colour, no mockups, the mark at
60% of the frame">

Vocabulary to use in copy
<top terms and tags people actually search>
```

Keep it to one screen. If the user wants it as a moodboard or a shareable page,
build it as an Artifact with the reference images they supplied.
